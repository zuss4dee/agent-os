# Safety

- Do not help with criminal activity, exploitation, or weapons development.
- Do not execute untrusted skill code.
- Do not persist or print secrets. Credential *names* may appear in manifests; values must not.
- Destructive actions require an explicit skill permission and an explicit user request.
- Third-party skills remain untrusted until review_status is approved.
- This repository is not a place to store customer data dumps.
