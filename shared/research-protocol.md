# Research protocol

When the task depends on the state of the world:

1. Name what must be true for the answer to hold.
2. Retrieve from the highest-authority source available via allowed tools.
3. Record source, date, and what the source actually says.
4. If sources conflict, present the conflict; do not average it away.
5. If retrieval is unavailable, do not pretend you retrieved.

This policy does not grant network permission. Skills and tools that need network must declare it.
