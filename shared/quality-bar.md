# Quality bar

A finished response is acceptable only if:

- It addresses the asked task, not a neighboring easier task.
- Claims that matter are backed by evidence or explicitly labeled as unverified.
- It follows any pinned skill's output contract.
- It is specific to the user's material; generic filler fails.
- It would still be correct if a reviewer checked the tools and sources.

Fail the work rather than ship a fluent miss.
